# Telephone Formatter

A simple web app that formats telephone numbers into the format: +(123) - 4567890


## 🚀 Features
- Automatically formats input as you type
- Restricts non-numeric characters
- Clean and minimal UI

## 📂 Project Structure
- `index.html` → Main HTML file
- `style.css` → Styling
- `script.js` → JavaScript logic

## ▶️ Usage
1. Clone the repo: git clone https://github.com/your-username/telephone-formatter.git
2. Open index.html in your browser.
3. Start typing a phone number and watch it format automatically!
